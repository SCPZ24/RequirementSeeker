# Agent M1 Deterministic Consensus Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add deterministic, trust-boundary-safe three-author consensus rules over a validated single-video active snapshot.

**Architecture:** `AnalysisRequest` remains the host-supplied full active snapshot and owns duplicate-ID, video-isolation, and retention validation. A pure rules module receives that request plus an explicit `NeedCluster`, validates references, excludes unknown/self/duplicate authors, selects deterministic evidence, and returns `ConsensusDecision`. Cross-day accumulation uses a test-only store because production persistence belongs to the host.

**Tech Stack:** Python 3.12, Pydantic 2, pytest, Ruff, mypy strict, uv.

- [x] **Step 3: Implement the minimal evaluator**

Create this public API in `rules/consensus.py`:

```python
RULES_VERSION = "m1.0"


def evaluate_consensus(request: AnalysisRequest, cluster: NeedCluster) -> ConsensusDecision:
    comments = {comment.comment_id: comment for comment in request.comments}
    if any(comment_id not in comments for comment_id in cluster.comment_ids):
        return _failed(cluster, "cluster_references_unknown_comment")
    if request.video.author_id is None:
        return _failed(cluster, "video_author_unknown")

    representatives: dict[str, Comment] = {}
    ordered = sorted(
        (comments[comment_id] for comment_id in cluster.comment_ids),
        key=lambda item: (item.first_collected_at, item.comment_id),
    )
    for comment in ordered:
        if comment.author_id is None or comment.author_id == request.video.author_id:
            continue
        representatives.setdefault(comment.author_id, comment)

    if len(representatives) < 3:
        return _failed(cluster, "insufficient_independent_authors")
    return ConsensusDecision(
        cluster_id=cluster.cluster_id,
        passed=True,
        reason_code="independent_author_threshold_met",
        evidence=[_evidence(comment) for comment in representatives.values()],
    )
```

Private helpers return failed decisions with empty evidence and copy exact trusted comment text into `Evidence`. The module docstring must state that semantic clustering remains M2 work.

The store upserts by stable `comment_id`, accepts identical replay, rejects a changed payload with `ValueError("comment_id_conflict")`, and returns only comments active at the supplied time. It only assembles `AnalysisRequest.comments`; no production persistence API is added.

```python
def test_two_plus_one_cross_day_snapshot_passes():
    store = SnapshotStore()
    store.ingest(day_one_comments[:2])
    store.ingest(day_two_comments[2:])
    value = request_at(day_two, comments=store.active_at(day_two))
    assert evaluate_consensus(value, cluster_from(value)).passed is True


def test_exact_replay_is_idempotent():
    store = SnapshotStore()
    store.ingest(all_comments)
    store.ingest(all_comments)
    assert len(store.active_at(analysis_time)) == len(all_comments)


def test_expired_comments_are_not_available_for_new_consensus():
    store = SnapshotStore()
    store.ingest(expired_comments)
    assert store.active_at(after_expiry) == []


def test_conflicting_replay_is_rejected():
    store = SnapshotStore()
    store.ingest([comment])
    with pytest.raises(ValueError, match="comment_id_conflict"):
        store.ingest([comment.model_copy(update={"author_id": "changed"})])
```
