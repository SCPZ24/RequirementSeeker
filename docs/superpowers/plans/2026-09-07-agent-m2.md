# Agent M2 Deterministic Model Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the offline M2 path from a validated sampling manifest through a deterministic fake model gateway to trusted need signals, same-video clusters, and M1 consensus decisions.

**Architecture:** Keep `AnalysisRequest v1` unchanged and add a separate `SamplingManifest` contract. Small synchronous components own sampling, batching, gateway transport, budget, cache, signal validation, clustering, and orchestration; every generated reference is checked against trusted request data before it can reach M1. `ScenarioModelGateway` exercises the same port and failure semantics that a later real adapter must satisfy.

**Tech Stack:** Python 3.12, Pydantic 2, pytest, Ruff, mypy strict, uv, Hatchling.

```python
    manifest_id: Identifier
    platform: Platform
    video_id: Identifier
    captured_at: Timestamp
    reported_total: NonNegativeInt | None
    collection_target: PositiveInt
    collected_total: NonNegativeInt

    pages_succeeded: NonNegativeInt

    distinct_author_count: NonNegativeInt
    exact_duplicate_count: NonNegativeInt
    normalized_duplicate_count: NonNegativeInt
    video_metrics: VideoMetrics | None
    candidate_comment_ids: list[Identifier]
    stratum_comment_ids: dict[str, list[Identifier]]

    @model_validator(mode="after")
    def integrity(self) -> Self:
        if self.pages_succeeded > self.pages_requested:
            raise ValueError("successful_pages_exceed_requested_pages")
        if self.author_id_present > self.collected_total:
            raise ValueError("author_count_exceeds_collected_total")
        candidates = set(self.candidate_comment_ids)
        if any(item not in candidates for values in self.stratum_comment_ids.values() for item in values):
            raise ValueError("stratum_comment_id_not_in_candidate_pool")
        return self
```

```python
def assess_quality(manifest: SamplingManifest) -> SamplingQuality:
    completion = min(manifest.collected_total / max(manifest.collection_target, 1), 1.0)
    page_rate = manifest.pages_succeeded / max(manifest.pages_requested, 1)
    author_rate = manifest.author_id_present / max(manifest.collected_total, 1)
    duplicate_rate = (
        manifest.exact_duplicate_count + manifest.normalized_duplicate_count
    ) / max(manifest.collected_total, 1)
    if completion >= 0.9 and page_rate >= 0.9 and author_rate >= 0.8 and duplicate_rate <= 0.25 and manifest.distinct_author_count >= 3:
        return SamplingQuality("usable", completion, page_rate, author_rate, duplicate_rate)
    if completion >= 0.6 and page_rate >= 0.6 and author_rate >= 0.5 and len(manifest.available_strata) >= 2 and manifest.distinct_author_count >= 3:
        return SamplingQuality("degraded", completion, page_rate, author_rate, duplicate_rate)
    return SamplingQuality("insufficient", completion, page_rate, author_rate, duplicate_rate)


def dynamic_target(population: int, max_comments: int, direction_factor: float, quality_factor: float) -> int:
    base = min(population, ceil(32 + 14 * log2(max(population, 1))), max_comments)
    return min(ceil(base * direction_factor * quality_factor), population, max_comments)
```

```python
class ModelGateway(Protocol):
    def invoke(self, request: ModelCallRequest) -> ModelCallResponse: ...


class ModelGatewayError(RuntimeError):
    def __init__(self, code: GatewayErrorCode, *, retryable: bool) -> None:
        super().__init__(code)
        self.code = code
        self.retryable = retryable
```

`ModelCallRequest` contains only invocation identity, stage, model refs, prompt/schema versions, controlled blocks, output limit, timeout, attempt, and scenario ID. `ModelCallResponse` contains an untrusted mapping, model identity, finish reason, and optional `TokenUsage`; secret values are impossible to represent.

```python
def reserve(self, *, input_tokens: int, output_tokens: int) -> Reservation:
    requested = BudgetDelta(model_calls=1, input_tokens=input_tokens, output_tokens=output_tokens)
    if not self._can_fit(requested):
        raise BudgetLimitExceeded(self._first_exceeded_resource(requested))
    self._reserved += requested
    return Reservation(self._next_id(), requested)


def settle(self, reservation: Reservation, usage: TokenUsage | None) -> None:
    self._reserved -= reservation.delta
    actual = reservation.delta if usage is None else BudgetDelta(1, usage.input_tokens, usage.output_tokens)
    self._consumed += actual
```

- [ ] **Step 4: Implement canonical cache keys, minimum expiry, and cache events**

The key includes exactly the nine approved decision fields. `put` accepts only `ValidatedStageValue`, stores no raw response, and requires an expiry. `get` reports `hit`, `miss`, or `expired`; expired entries are deleted. Revalidation remains the caller's responsibility.

```python
def analyze_m2(request: AnalysisRequest, manifest: SamplingManifest, gateway: ModelGateway, cache: SemanticCache) -> M2AnalysisResult:
    ensure_manifest_matches_request(request, manifest)
    plan = plan_sampling(request, manifest)
```
